Given where we are, I want to give you a method that is supported and safe for an existing Jenkins installation.

Step 1: Stop Jenkins
docker stop jenkins
Step 2: Create the init script directory
mkdir -p ~/jenkins_home/init.groovy.d
Step 3: Create reset-admin.groovy
cat > ~/jenkins_home/init.groovy.d/reset-admin.groovy <<'EOF'
import jenkins.model.*
import hudson.security.*

def instance = Jenkins.get()

if (!(instance.getSecurityRealm() instanceof HudsonPrivateSecurityRealm)) {
    println("Current security realm is not HudsonPrivateSecurityRealm")
    return
}

def realm = instance.getSecurityRealm()

def user = realm.getUser("admin")

if (user == null) {
    println("Admin user not found, creating it...")
    realm.createAccount("admin", "admin")
} else {
    println("Resetting password for existing admin user...")
    user.addProperty(HudsonPrivateSecurityRealm.Details.fromPlainPassword("admin"))
    user.save()
}

instance.save()

println("========================================")
println("Admin password has been reset")
println("Username : admin")
println("Password : admin")
println("========================================")
EOF
Step 4: Start Jenkins
docker start jenkins

Wait about 30 seconds.

Step 5: Watch the logs
docker logs -f jenkins

You should see:

Resetting password for existing admin user...
========================================
Admin password has been reset
Username : admin
Password : admin
========================================
Step 6: Log in
Username: admin
Password: admin
Step 7: Remove the script

Once you've successfully logged in:

rm ~/jenkins_home/init.groovy.d/reset-admin.groovy
docker restart jenkins
If this script does not print the "Admin password has been reset" message

Stop immediately and don't try other scripts.

Instead, copy the output from:

docker logs jenkins | tail -100
